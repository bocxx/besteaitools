## LinkedIn

Wil je AI gebruiken zonder dat je tekst naar een cloudserver gaat? Met Ollama draai je een taalmodel gratis en lokaal — op Mac, Windows of Linux.

De kern:

- Installeren duurt minuten: Homebrew op Mac, een installer op Windows, één script op Linux.
- `ollama run llama3.2` haalt een model op en start meteen een gesprek.
- Je RAM bepaalt het model: 8 GB → een klein 3B-model, 16 GB+ → een 7-8B-model.
- Alles blijft op je eigen machine — geen data naar buiten, geen kosten per gebruik.

Handig voor wie met gevoelige documenten werkt of gewoon geen maandbedrag wil.
