# AI Tools Radar – Make · Grok · Claude (Avond 23 april)

Vandaag een bonte mix: van een neuraal netwerk dat draait op een Macintosh uit 1989 tot prijswijzigingen bij Claude en een nieuwe Word-integratie. Anthropic schuift Claude Code naar het duurdere Max-abonnement, terwijl ontwikkelaars experimenteren met Spice-simulaties en oscilloscopen die Claude aansturen. Tussen de launches door duikt een discussie op over het einde van video in ChatGPT.

## 🚀 Nieuwe launches

- **MacMind** — Een transformer neuraal netwerk dat draait in HyperCard op een Macintosh uit 1989, voor wie nostalgie en low-level ML wil combineren. [Hacker News](https://github.com/SeanFDZ/macmind)
- **Faceoff** — Terminal-interface om NHL-wedstrijden te volgen, voor developers die hun sportdata liever in de command line zien. [Hacker News](https://www.vincentgregoire.com/faceoff/)
- **Alien** — Self-hosting tool met remote management, geschreven in Rust, voor wie controle wil zonder cloud-afhankelijkheid. [Hacker News](https://news.ycombinator.com/item?id=47835599)
- **Stage** — Code review-tool die menselijke controle terugbrengt in het reviewproces, met 106 reacties op Hacker News. [Hacker News](https://stagereview.app/)
- **Spice simulation → oscilloscope → verification with Claude Code** — Workflow die Spice-simulaties koppelt aan een oscilloscoop en verificatie via Claude Code, interessant voor hardware-engineers. [Hacker News](https://lucasgerads.com/blog/lecroy-mcp-spice-demo/)
- **GPT-Rosalind** — Nieuw GPT-model gericht op life sciences research, aangekondigd op Reddit's singularity-community. [Reddit r/singularity](https://reddit.com/r/singularity/comments/1sne2e7/introducing_gptrosalind_for_life_sciences_research/)

## 💬 Wat valt op

Claude domineert de feature-updates met zowel een prijsverhoging als een nieuwe Word-integratie, wat laat zien dat Anthropic inzet op enterprise-workflows terwijl het tegelijk de toegang tot geavanceerde functies afschermt achter duurdere abonnementen. De launches zijn opvallend divers: van retro-experimenten met oude hardware tot moderne self-hosting tools in Rust, zonder duidelijke rode draad. Het meest concrete signaal komt uit de deep-dive: OpenAI trekt video terug uit ChatGPT, een beweging die haaks staat op de verwachting dat multimodaliteit alleen maar zou groeien. Tussen de regels door blijft de spanning zichtbaar tussen open experimenten en commerciële platformkeuzes.
