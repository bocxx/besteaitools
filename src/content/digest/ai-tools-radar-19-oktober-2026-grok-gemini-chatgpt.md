De updates van deze week schuiven AI-assistenten verder richting zelfstandig werk. Claude Cloud Sessions houden Claude Code actief zonder open laptop, en Grok Bot kan via een eigen e-mailadres namens gebruikers contact leggen met bedrijven. Tegelijk wordt spraak een serieuze manier om te werken: ChatGPT voert taken in de browser uit op een gesproken opdracht, en xAI richt Grok Voice 3.0 op klantgesprekken. Aan de launch-kant valt Parsimony op, een open-source benchmark die meet hoeveel code AI-modellen toevoegen.
