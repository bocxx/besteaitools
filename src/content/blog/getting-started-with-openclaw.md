Welcome to OpenClaw! This guide will walk you through the installation process and help you get your first AI assistant up and running.

## Prerequisites

Before we begin, make sure you have:
- Node.js 18+ installed
- A valid API key from your preferred AI provider
- 10 minutes of free time

## Installation

Getting started is simple:

```bash
npm install -g openclaw
openclaw init
```
