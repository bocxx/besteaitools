Sinds 14 september 2026 werk je in Claude Code met een lagere weekly limiet dan de afgelopen zomer — ook al noemt Anthropic het zelf een "verhoging van 25%". De tijdelijke boost van 50% die van mei tot september gold, is namelijk komen te vervallen. Wat er precies verandert, voor wie, en hoe je met minder ruimte toch je workflow op peil houdt, lees je hieronder. Voor de bredere Claude Code-context: [wat Claude Code Desktop allemaal kan](https://www.hetlaatsteainieuws.nl/nieuws/claude-code-desktop-grote-update).

## Wat er precies veranderde

Van 13 mei tot en met 13 september 2026 gaf Anthropic Pro-, Max-, Team- en seat-based Enterprise-gebruikers een tijdelijke boost van 50% extra weekly limiet in Claude Code ([Bron: Claude Help Center](https://support.claude.com/en/articles/15910845-claude-code-may-august-2026-weekly-limits-promotion)). Die promotie liep na vier verlengingen definitief af. Sinds 14 september 2026 geldt in plaats daarvan een permanente verhoging van 25% ten opzichte van de limiet van vóór de hele promotieperiode — officieel bevestigd door Anthropic via het @ClaudeDevs-account op X en herhaald in het eigen Helpcenter-artikel.

Het rekensommetje is de crux: 25% hoger dan de oude basis is minder dan de 50% boost die je deze zomer gewend was. Netto kom je dus op ongeveer 17% minder weekly capaciteit uit dan in augustus. Free-gebruikers en consumption-based Enterprise-klanten deden nooit mee aan de promotie en merken dus helemaal niets van de overgang.

> **💡 Beginner-tip:** je weekly limiet reset elke week op een vast moment — check dit in Claude Code via je accountoverzicht, zodat je weet wanneer je "budget" weer volloopt.

## Zo houd je grip op je lagere limiet

1. **Wis conversaties die klaar zijn.** Draai `/clear` zodra een taak is afgerond in plaats van dezelfde sessie eindeloos door te laten lopen — een opgestapelde geschiedenis kost bij elke volgende prompt opnieuw tokens.
2. **Comprimeer lange sessies.** Gebruik `/compact` bij taken die wél in dezelfde context moeten blijven, zoals een langlopende refactor. Claude Code vat de sessie dan samen in plaats van de hele geschiedenis mee te slepen.
3. **Zet een tokenbesparende skill aan.** De gratis Caveman-skill snoeit tot 65% van de filler uit Claude Code's output ([bekijk hoe je Caveman instelt](/nieuws/caveman-claude-code-tokens-besparen)) — direct minder verbruik zonder functionaliteit te missen.
4. **Controleer je verbruik tussentijds.** Anthropic kondigde in dezelfde update betere zichtbaarheid van je resterende weekly quotum aan als compensatie voor de verlaging; hou de interface in de gaten voor die toevoeging.

> **⚡ Gevorderden:** overweeg voor zware, herhalende taken een aparte sessie met een goedkoper model in te zetten en Opus-niveau te reserveren voor het werk waar het verschil echt telt — dat scheelt meer dan welke losse skill dan ook.

## Alternatief als de limiet echt knelt

Loop je structureel tegen de nieuwe limiet aan, dan is opschalen naar een hoger plan één optie — maar niet de enige. Sommige teams combineren Claude Code met een los coding-abonnement zoals [Z.ai GLM](/nieuws/z-ai-glm-coding-plan-claude-code-koppelen) voor het routinewerk, en reserveren Claude Code zelf voor taken waar de kwaliteit het verschil maakt. Check ook je factuuroverzicht: [zo controleer je precies waar je Claude-verbruik aan opgaat](/nieuws/claude-rekening-factuur-controleren).

## Checklist: ben je klaar?

- [ ] Weet welk plan je hebt (Pro, Max, Team, seat-based Enterprise) en of dit je raakt
- [ ] `/clear` en `/compact` als gewoonte in je workflow opgenomen
- [ ] Caveman-skill of vergelijkbare tokenbesparing geïnstalleerd
- [ ] Resetmoment van je weekly limiet gecontroleerd in je accountoverzicht
- [ ] Bij structureel tekort: alternatief plan of gecombineerde aanpak overwogen
