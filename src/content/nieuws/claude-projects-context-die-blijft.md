Veruit de meeste mensen gebruiken Claude als een losse chatbox: vraag stellen, antwoord krijgen, venster sluiten. Functioneel, maar je begint elke keer weer bij nul. Claude moet telkens opnieuw horen wie je bent, waar je aan werkt en hoe je je antwoorden wilt. Projects lost dat op — en het is de snelste manier om Claude van een handige assistent naar een ingewerkte collega te tillen.

## Wat een Project doet

Een Project is een aparte werkruimte die drie dingen bij elkaar houdt: **instructies** (hoe Claude moet werken), **documenten** (jouw kennis, geüpload) en alle **chats** die je erbinnen voert. Het verschil met een gewone chat is dat de context blijft hangen. Wat je één keer in het Project zet, kent Claude in elke chat daarbinnen — zonder dat je het opnieuw plakt.

Werk je aan een terugkerend onderwerp — een klant, een verslag, een vak — dan is dat het verschil tussen elke dag opnieuw uitleggen en meteen aan de slag.

> **💡 Beginner-tip:** Zie een Project als een map met een ingebouwd briefje voorop. De map bevat je bestanden, het briefje vertelt Claude hoe het ermee moet werken. Je schrijft het briefje één keer.

## Zo stel je een Project in

Projecten zitten in het betaalde Pro-plan, waar ze onbeperkt beschikbaar zijn. Het opzetten kost een paar minuten:

**Stap 1 — Maak een Project aan** en geef het een duidelijke naam, bijvoorbeeld de klant of het onderwerp waar het om draait.

**Stap 2 — Schrijf de projectinstructies.** Dit is de belangrijkste stap. Zet hier alles in wat je anders bij elke chat zou herhalen: wie je bent, in welke taal en toon je wilt schrijven, welke termen je hanteert, en wat het doel is. Hoe concreter, hoe consistenter de antwoorden.

**Stap 3 — Upload je documenten.** Brondocumenten, een stijlgids, eerdere voorbeelden — alles wat Claude moet kennen om jouw werk te begrijpen. Die kennis geldt dan voor elke chat in het Project.

**Stap 4 — Start een chat binnen het Project** en merk dat je meteen ter zake kunt. Geen achtergrond meer plakken; Claude weet het al.

## Het model onder de motorkap

Op Pro draait Claude standaard op Sonnet 4.6, een gebalanceerd model dat voor de meeste taken ruim voldoet. Voor de zwaarste redeneer- of analyseklussen is er beperkte toegang tot het krachtigere Opus-model. Voor het werken met projectcontext maakt de modelkeuze niet uit — de projectkennis werkt met elk model dat je kiest.

> **⚡ Gevorderden:** Maak aparte Projecten per type werk in plaats van één grote bak. Een Project "Klantmails" met je toon en voorbeelden levert scherpere output dan een algemeen Project waarin alles door elkaar loopt. Hoe specifieker de context, hoe beter het antwoord.

## Begin klein

Je hoeft niet meteen tien Projecten op te zetten. Kies één terugkerende klus, maak er een Project voor, en schrijf de instructies goed. Binnen een dag merk je het verschil.
